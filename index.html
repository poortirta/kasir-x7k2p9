Database Barang (barang.sql)

Katalog harga dari database barang sudah tertanam di aplikasi ini: . Impor ulang akan memperbarui nama, kategori, dan harga barang yang kodenya sama. Stok dan barang lain tidak berubah.

Backup & Pulihkan Data

Data utama ada di Supabase. File backup (.json) tetap berguna sebagai cadangan tambahan, simpan di flashdisk atau Google Drive. Memulihkan backup atau menghapus semua data juga mengganti data di server.
